# Candylia_1

## Descripción

**Candylia** es un proyecto académico desarrollado para la gestión de una dulcería. El sistema busca facilitar el manejo de las ventas y el inventario, permitiendo tener un mayor control sobre los gastos y las operaciones del negocio.

El sistema cuenta con diferentes roles de usuario, de acuerdo con las funciones que cada persona puede realizar.

## Objetivo

El objetivo principal de Candylia es **manejar de manera correcta los gastos y tener un mayor control sobre las ventas, el inventario y los usuarios de la dulcería**.

## Tecnologías utilizadas

* **Frontend:** React
* **Backend:** Spring Boot
* **Lenguaje:** Java
* **Base de datos:** MySQL

## Roles de usuario

El sistema cuenta con tres roles:

### Administrador

* Tiene acceso a todas las funcionalidades del sistema.
* Gestiona los usuarios.
* Gestiona el inventario.
* Gestiona las ventas.

### Empleado

* Tiene acceso a la gestión del inventario.

### Cliente

* Puede acceder al sitio web.
* Puede realizar compras.

## Funcionalidades actuales

Actualmente el sistema cuenta con:

* Registro de usuarios.
* Inicio de sesión.
* Manejo de roles de usuario.
* Acceso al sistema dependiendo del rol.
* Conexión entre React, Spring Boot y MySQL.

## Base de datos

Actualmente la base de datos contiene principalmente la información relacionada con los usuarios.

La base de datos se encuentra desarrollada en **MySQL**.

## Tecnologías y arquitectura

El proyecto utiliza una arquitectura dividida en:

```text
Candylia
│
├── Frontend
│   └── React
│
├── Backend
│   └── Spring Boot + Java
│
└── Base de datos
    └── MySQL
```
